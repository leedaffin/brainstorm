# BrainStorm

Team chat for MonkeyMoos and HungryMoose, by Brain Candy Studio.

- Live: https://brainstorm.braincandystudio.co.uk
- Plain HTML/CSS/JS app (no build step). Cloudflare Pages serves this folder as-is.
- Backend: Supabase project "BrainStorm" (London).

Every push to `main` goes live automatically.
